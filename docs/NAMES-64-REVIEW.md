## The rule

1. One name: the day-to-day half becomes the adjective, the people archetype stays the noun ("Cozy Golden Retriever").
2. The default is adjective + noun; a cell is overridden only when a clearly better phrase exists (2 of 64).
3. One line under the name merges both halves, in both voices (Make it fun, Heart to heart).

## Known for: 3 tells per player

How the 3 tells are picked:

1. Start from the player's fired tags in their display order (strong tags first by net support, then coverage share), the same order library.json tagRules.firing sets.
2. Skip any tag with shareable false (T11A, T11B kids; T21A, T21B weddings). They can still appear on owner-only screens, never on the share image.
3. Take the first 3, at most one per chapter when the fired list allows it; if the next tag repeats a chapter already used, try the following one and fall back to it only when nothing else is left.
4. If fewer than 3 are left, fill from the player's strongest stat ends (strongest first) using the fallback map, skipping any tag already shown or whose pair is shown.
