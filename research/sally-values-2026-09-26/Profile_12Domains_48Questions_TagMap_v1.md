# 12类生活议题：48题探索初稿与96个候选方向标签

版本：v1｜2026-09-26｜适用目的：与成年用户共同探索其态度、偏好及条件性取舍。

## 使用边界与作答方式

本稿根据本次对话已确认的12个话题领域原创设计，并非已验证心理量表。48题覆盖48个观察点，96个名称是便于整理回答的候选方向描述，不是96种独立心理特质。A/B是讨论锚点，不是严格的数学反义词，也没有正确答案；两边可能兼容。

建议每题先选“更接近A／略偏A／两边都认同或看条件／略偏B／更接近B”，另外提供“都不符合，请补充”“不适用”“尚未想过”“不愿回答”。“两边都认同”必须追问各自成立的条件，不与“不知道”合并。性、婚育、家庭经历等题可以跳过；没有伴侣或未经历相关情境不算缺失人格。

每题再问：为什么？哪一个条件改变会使你换边？你最近一次实际怎么做？“我认为应该”“我自己想要”“我实际上做过”单独记录。情境中的经济、健康、照顾责任和可选择空间不能省略。

不要在作答前显示标签名称，以免引导。每个答案只建立这个情境中的线索；不要换算出女权程度、依恋类型、善恶、健康诊断或固定人格总分。

## 完整题目

### 性别与女权

**Q01｜两个人都能胜任赚钱和照顾家庭，时间条件也相近。你认为家庭分工应该从哪里开始谈？**

- A：先谈各自意愿和优势，不预设性别角色。
- B：可以先按男主外、女主内的习惯分，再按实际调整。
- 条件追问：你觉得这是适合自己的安排，还是大多数人都应该如此？

设计者查看：A可支持“协商分工取向”；B可支持“传统分工预设”。解释范围：分工原则；不能凭此认定女权身份。

**Q02｜一项创业资助希望改善女性获得资源较少的状况。在申请人条件相近时，你更支持哪种方式？**

- A：适度优先女性，补偿已有资源差距。
- B：不把性别作为排序条件，统一比较项目。
- 条件追问：如果看不到资源差距的可靠证据，你会改变答案吗？

设计者查看：A可支持“性别补偿措施支持”；B可支持“性别中立程序偏好”。解释范围：具体平权措施；两边都可能支持平等。

**Q03｜一位经济条件充足、也保有退路的女性，自愿选择传统家庭分工，并公开分享。谈论她的选择时，你更想先强调什么？**

- A：她有选择这种生活的自由，不需要证明足够独立。
- B：尊重她的同时，也应讨论这种内容传递的社会期待。
- 条件追问：什么情况下，你会从尊重选择转为提出批评？

设计者查看：A可支持“个体选择优先”；B可支持“结构影响关注”。解释范围：讨论优先次序；两种立场可以并存。

**Q04｜一对男女伴侣都愿意照顾孩子，换谁工作收入都相近。如果女方工作、男方全职育儿，你觉得呢？**

- A：只要双方愿意，这与相反分工一样自然。
- B：我不认为应该禁止，但自己仍更喜欢相反的安排。
- 条件追问：你会接受别人这样做，但不希望自己这样做吗？

设计者查看：A可支持“非传统性别分工接受”；B可支持“个人传统角色偏好”。解释范围：接受度与个人偏好；不能等同权利立场。

### 爱情、性与忠诚

**Q05｜在没有越界或隐瞒的情况下，你更希望伴侣与你怎样相处？**

- A：大部分空闲时间一起过，经常分享彼此的日常。
- B：亲密之余各有固定的独处和社交时间。
- 条件追问：你需要的相处频率会随着压力或工作改变吗？

设计者查看：A可支持“高共同时间偏好”；B可支持“关系独立空间偏好”。解释范围：相处偏好；不能诊断依恋类型。

**Q06｜你们原先约定排他关系。伴侣没有身体出轨，却瞒着你长期与别人暧昧，并分享原本只对你说的心事。你最难接受什么？**

- A：即使没有身体接触，亲密的排他性也被破坏了。
- B：最关键是隐瞒和违约；边界本应由我们共同说清。
- 条件追问：如果事前明确同意这种互动，你的感受会改变吗？

设计者查看：A可支持“情感排他重视”；B可支持“关系约定重视”。解释范围：越界判断依据；不是对出轨严重度的普遍排名。

**Q07｜有吸引力、彼此尊重，也已经沟通好同意与保护措施，但还没有长期承诺。对你而言，发生性关系是否合适？**

- A：可以，长期承诺不是我必需的前提。
- B：我更希望先有明确、稳定的关系承诺。
- 条件追问：这是你自己的舒适边界，还是你也希望别人照此选择？

设计者查看：A可支持“性与承诺可分离”；B可支持“承诺先于性偏好”。解释范围：本人明确自述的亲密偏好；不推断经历或性取向，可跳过。

**Q08｜一段关系没有欺骗、暴力或控制，但连续几个月因生活习惯发生小摩擦。双方都愿意改变，你更倾向？**

- A：约定具体调整办法，给彼此一段修复时间。
- B：即使都没有错，也可以因长期不合适而结束。
- 条件追问：什么迹象会让你从继续尝试改为离开？

设计者查看：A可支持“关系修复优先”；B可支持“关系适配优先”。解释范围：非危险情境下的修复倾向；不是忍耐伤害要求。

### 婚姻、生育与家庭形式

**Q09｜如果感情稳定，双方也能用其他方式处理共同财务和照顾安排，你仍然需要结婚才觉得关系完整吗？**

- A：婚姻本身对我有重要的承诺或仪式意义。
- B：关系质量足够好，不结婚也可以完整。
- 条件追问：你在意的是仪式、社会承认、具体保障，还是别的原因？

设计者查看：A可支持“婚姻形式重视”；B可支持“非婚关系接受”。解释范围：婚姻意义；不假定不同法律安排完全等效。

**Q10｜暂时不考虑伴侣和父母期待，只问你此刻对成为父母的感受，更接近哪边？**

- A：这是我向往的人生经历。
- B：我的理想人生可以不包含养育孩子。
- 条件追问：是不想、还没想好，还是想但现实条件不允许？

设计者查看：A可支持“当前育儿向往”；B可支持“当前非育儿生活倾向”。解释范围：当前愿望；不能当作永久生育决定。

**Q11｜你已经明确想要孩子，也有可行的基本照顾条件。未来两年同时出现一次重要职业机会，你更愿意？**

- A：适度调整事业节奏，保留原来的育儿时间安排。
- B：先把握职业机会，再重新讨论育儿时间。
- 条件追问：如果伴侣可以承担更多照顾，你会改选吗？

设计者查看：A可支持“育儿时间优先”；B可支持“职业阶段优先”。解释范围：仅适用于想育儿者；计划选择，不评判生育时机。

**Q12｜婚礼预算由你们自己承担，基本财务不受影响。你更想把预算花在哪里？**

- A：一次亲友共同参与、仪式完整的庆祝。
- B：简单仪式，把更多钱留给住房、旅行或未来计划。
- 条件追问：如果家人强烈期待盛大婚礼，你愿意增加多少投入？

设计者查看：A可支持“婚礼仪式投入偏好”；B可支持“共同生活投入偏好”。解释范围：婚礼资源偏好；不能直接等同虚荣或节俭。

### 金钱、阶层与公平

**Q13｜朋友靠父母支持买了房。她说自己也很努力。你评价她目前的成功时，更想强调哪一面？**

- A：她的努力仍应得到认可，资源不抹掉个人付出。
- B：也应明确家庭起点，不能只讲个人努力。
- 条件追问：如果她公开承认家庭支持，你对她的评价会不同吗？

设计者查看：A可支持“个人努力归因关注”；B可支持“起点资源归因关注”。解释范围：解释侧重点；两种原因可同时成立。

**Q14｜你和伴侣合住，收入约相差一倍，居住需求相近，家务投入也相近。共同支出你更赞成？**

- A：按收入比例分，让双方承担的压力接近。
- B：金额各半，双方对共同生活承担同样的费用。
- 条件追问：如果高收入一方坚持升级住房，费用如何变化？

设计者查看：A可支持“支付能力比例分担”；B可支持“等额费用分担”。解释范围：特定条件下的财务公平规则。

**Q15｜一位亲近朋友急需一笔你借得起、但损失后会心疼的钱。对方暂时说不准什么时候还，你更倾向？**

- A：提供自己能接受的有限金额，暂时不把归还日期放第一。
- B：先把归还安排说清楚，再决定是否借。
- 条件追问：什么金额以上你会改变处理方式？

设计者查看：A可支持“关系援助优先”；B可支持“借贷边界优先”。解释范围：援助决策；拒借不等于缺乏善意。

**Q16｜一个项目的利润由团队分配。大家承担的工作量相近，但贡献效果有差异，你更认可？**

- A：主要按可说明的贡献分，结果可以拉开差距。
- B：保留较强的均分部分，认可共同承担与合作。
- 条件追问：如果贡献很难测量，你支持怎样的分配？

设计者查看：A可支持“贡献差异分配”；B可支持“共同参与分配”。解释范围：团队资源规则；不能推断完整政治或经济立场。

### 工作、野心与成功

**Q17｜两份工作都能满足基本生活。一份收入更高但内容不喜欢，另一份收入较低却很有兴趣，你更倾向？**

- A：先选高收入，用工作外的时间发展兴趣。
- B：选有兴趣的工作，接受相应的消费限制。
- 条件追问：收入差距达到多少，你会改选？

设计者查看：A可支持“工作收入优先”；B可支持“工作兴趣优先”。解释范围：有基本保障条件下的职业偏好。

**Q18｜你已完成自己的任务。同事遇到一个并非紧急、明天也能处理的问题，希望你今晚留下帮忙，你更倾向？**

- A：这次留下，团队互相补位很重要。
- B：说明自己今晚有安排，约好明天协助。
- 条件追问：如果这种请求每周都出现，你的答案会变吗？

设计者查看：A可支持“团队补位优先”；B可支持“非紧急工作边界”。解释范围：偶发请求情境；不直接判断责任心。

**Q19｜你有一笔可维持半年生活的储蓄。一份稳定工作与一个收入不确定、但很想尝试的创业机会同时出现，你更倾向？**

- A：先保留稳定工作，把机会作为副业测试。
- B：投入半年认真尝试，接受储蓄减少的可能。
- 条件追问：有家人需要你供养时，会改变什么？

设计者查看：A可支持“渐进试错偏好”；B可支持“集中冒险偏好”。解释范围：给定缓冲条件下的职业风险偏好。

**Q20｜未来三年，两种工作都可维持你想要的生活。你更愿意？**

- A：投入更多时间换取晋升和更大的职责。
- B：维持目前职责，保留更多工作外的时间。
- 条件追问：是目前阶段如此，还是长期都这样？

设计者查看：A可支持“职业晋升优先”；B可支持“生活时间优先”。解释范围：阶段性职业投入；不是懒惰或缺乏能力。

### 原生家庭、孝顺与边界

**Q21｜父母愿意给你首付，但条件是买在他们附近。你更倾向？**

- A：如果没有特别冲突，可以接受，帮助也包含家庭期待。
- B：只有地点也符合自己的计划才接受，否则宁愿晚点买。
- 条件追问：他们是在提出偏好，还是要求长期服从？这会影响你吗？

设计者查看：A可支持“家庭支持附带协商”；B可支持“居住自主边界”。解释范围：经济帮助与选择权的边界。

**Q22｜父母暂时需要长期照顾。你能出一部分钱，兄弟姐妹也有能力，但你搬回去会影响工作，你更愿意？**

- A：优先亲自承担较多照顾，其他安排之后调整。
- B：先组织亲属与专业照顾，保留自己的工作。
- 条件追问：父母需要的程度、与你的关系，会怎样改变答案？

设计者查看：A可支持“亲自照顾偏好”；B可支持“协作照顾偏好”。解释范围：照顾方式；不能等同孝顺高低。

**Q23｜在不影响你基本生活的前提下，父母希望你持续资助成年弟妹，但对方并非暂时遇到意外困难，你更倾向？**

- A：家人之间可以长期互相托底，再谈责任分配。
- B：帮助可以有期限，希望对方建立自己的承担能力。
- 条件追问：如果弟妹有疾病或照顾责任，你会怎样调整？

设计者查看：A可支持“长期家族互助”；B可支持“有期限家庭援助”。解释范围：非紧急且具承担能力条件下的家庭义务。

**Q24｜你想搬到另一座城市，父母不赞成，但没有需要你留在身边照顾的现实原因，你会？**

- A：多花时间争取共识，必要时愿意延后计划。
- B：认真听取意见后，仍按自己的判断决定时间。
- 条件追问：你愿意延后多久？什么理由足以让你改变？

设计者查看：A可支持“家庭共识优先”；B可支持“成年自主决策”。解释范围：家庭意见与个人决策的优先次序。

### 友情、社交与人情

**Q25｜好朋友做了一件明显让另一个朋友受伤的事，事实已基本清楚。你更想先做什么？**

- A：先私下支持她稳定情绪，再谈怎样承担责任。
- B：先明确不同意她的行为，即使她暂时觉得我不站她这边。
- 条件追问：支持她这个人和支持她的做法，对你有什么区别？

设计者查看：A可支持“朋友情绪支持优先”；B可支持“朋友行为问责优先”。解释范围：回应顺序；两边都可能最终要求担责。

**Q26｜你和朋友都认可彼此，但几个月不主动联系。哪种说法更接近你？**

- A：重逢自然就好，不需要频繁联系证明关系。
- B：我需要一些主动联系，才能感到关系被认真维护。
- 条件追问：是所有朋友都这样，还是只对最亲近的人？

设计者查看：A可支持“低频联系舒适”；B可支持“主动联系需要”。解释范围：联络需求；不是友情真伪判断。

**Q27｜朋友连续几晚找你诉说同一个问题，你今天也很累，但没有紧急危险。你更倾向？**

- A：先陪她聊一会儿，再安排自己的休息。
- B：明确说今晚接不住，约另一个时间或其他支持。
- 条件追问：如果你连续一周都很累，会怎样处理？

设计者查看：A可支持“当下陪伴优先”；B可支持“支持容量边界”。解释范围：当前支持容量；不判断共情能力高低。

**Q28｜朋友办一场超出你舒适预算、但你勉强负担得起的庆祝活动，希望你参加。你更倾向？**

- A：为重要关系破例一次，之后减少其他开销。
- B：坦白预算，选择较便宜的方式单独庆祝。
- 条件追问：关系有多亲近、活动是否可替代，会改变答案吗？

设计者查看：A可支持“仪式人情投入”；B可支持“社交预算边界”。解释范围：特定人情支出；不等同抠门或虚荣。

### 身体、外貌与健康选择

**Q29｜一项纯粹为了外观的日常打理，让你更满意，但每天花一小时且并不影响工作要求。你更愿意？**

- A：保留它，好看带来的愉悦值得这段时间。
- B：简化它，把时间留给别的体验。
- 条件追问：如果没有人会看到，你还会想做吗？

设计者查看：A可支持“审美投入偏好”；B可支持“外貌打理简化”。解释范围：审美时间分配；不自动标记服美役。

**Q30｜一位朋友没有征求意见，你注意到她的身材变化，但不了解原因。你更认可？**

- A：不主动评价，等她自己决定是否谈。
- B：若很亲近，可以先问她是否愿意聊近况。
- 条件追问：如果你担心的是具体不适而不是外观，会怎样开口？

设计者查看：A可支持“身体话题不主动介入”；B可支持“身体话题先征询”。解释范围：身体谈话边界；不判断健康状况。

**Q31｜一项可自由选择的日常习惯让你很享受，也会轻微影响第二天的精神；没有已知禁忌。你更倾向？**

- A：大多数时候减少它，优先稳定的身体状态。
- B：给它保留一定频率，接受这部分生活代价。
- 条件追问：你能接受的影响到什么程度为止？

设计者查看：A可支持“状态稳定优先”；B可支持“享受与状态折中”。解释范围：本人感受下的生活取舍；非医疗建议。

**Q32｜你想改善日常状态。两种办法都可行，你更愿意采用？**

## 如何记标签，避免把情境误当成整个人

| 字段 | 记录内容 |
|---|---|
| 候选描述 | 例如“非紧急工作边界” |
| 依据 | Q18的选择、理由及原话，不能只留下AI概括 |
| 资料类型 | 原则主张／本人偏好／本人回忆的经历／另有证据的实际行为，分别存放 |
| 适用条件 | 偶发还是反复、风险与成本、有无照顾义务 |
| 相反或例外证据 | 她在其他情境中为何作出不同选择 |
| 资料状态 | 未知／单题线索／有补充情境／待澄清，不作为统计置信度 |
| 用户确认 | 她认为概括准确、部分准确或不准确；保留她的修订 |
| 时间 | 回答日期与当时生活阶段；允许日后改变 |

不采用“答A加1、累计80%就是某种人”之类未经校准的规则。若未来需要分数，应先验证题义、结构、信度、效度及不同群体的可比性。
