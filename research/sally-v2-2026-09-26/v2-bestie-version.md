# 生活議題測驗 v2｜閑蜜版題庫：你是不是最懂我的那個？

Sep 26, 2026 · @SallySo

## 遊戲流程

閨蜜版共四關，約6分鐘：猜型（6題）→ 猜她的選擇（12題）→ 猜標籤（12選N）→ 閨蜜限定：哪句最戳她。和男生版的差別在於，題目偏向閨蜜真正看得到的面向：家人、錢、友情、消費和戀愛狀態，語氣也更像互相吐槽。

**邀請文案（三選一）：**

- 姐妹，考你一下。你覺得你有多懂我？猜錯請我喝奶茶。
- 我測出來的結果有點扎心，你猜得到是哪一句嗎？
- 我也發給他了，想看看你們誰更懂我。

**進入前提示（閨蜜看到）：**

> 你要猜的是{名字}的選擇，不是你自己的。姐妹之間的默契，今天來驗收。你的答案只有{名字}看得到。

**隱私設定（分享前由她勾選）：**

| 項目 | 預設 | 說明 |
| --- | --- | --- |
| 戀愛標籤（第1、2對） | 開 | 閨蜜通常知道她的戀愛狀態 |
| 婚育標籤（第3、4對） | 關 | 勾選後才進入卡池 |
| 扎心句 | 關 | 勾選後才解鎖第四關 |
| Q07 性與承諾 | 永不進入 | 任何版本都不出現 |

每題都附選填欄位：你為什麼這麼猜？

## 第一關：猜型

6題二選一，每題對應一條軸，計分規則與男生版相同；她的軸若帶「彈性」徽章，選哪邊都算對。

**F1｜談戀愛的{名字}是哪種？**（R1）

- 黏人派：恨不得天天見面，什麼都要跟他分享。
- 獨立派：再愛也要有自己的時間，還要留時間給姐妹。

**F2｜你半夜找{名字}哭訴，她已經累到不行，她會？**（R2）

- 直接說：「我今天真的接不住，明天打給你。」
- 硬撐著陪你，自己的累之後再說。

**F3｜聊到結婚和以後的家，{名字}腦中的畫面比較像？**（R3）

- 老派：有儀式、有家的樣子，爸媽也會安心。
- 新派：怎麼過我們自己說了算，不照任何範本。

**F4｜發了一筆獎金，{名字}最可能？**（L1）

- 先存起來，安全感最重要。
- 訂機票，人生苦短。

**F5｜講到工作和人生進度，{名字}是？**（L2）

- 有野心：想做出點成績，也想早點把方向定下來。
- 很松弛：按自己的節奏走，別人幾歲結婚升職跟她無關。

**F6｜排隊、規定、公平這種事，{名字}比較像？**（L3）

- 規則派：大家都照規矩來最公平。
- 看情況派：規則是死的，人是活的。

## 第二關：猜她的選擇

12題都是閨蜜平常就可能聽她說過或親眼看過的情境。她選「略偏」或「更接近」都算那一邊；她選「兩邊都認同」「不適用」「只能這樣」或跳答的題目，依序由備用題補上。

**G1｜（Q05）{名字}理想中和男朋友的相處是？**

- A：大部分空閒都黏在一起。
- B：很親密，但各自有獨處和社交時間。

**G2｜（Q08）{名字}和男朋友為生活小事磨了好幾個月，沒有誰對不起誰。她會？**

- A：一起想辦法改，再給彼此一點時間。
- B：不合適就是不合適，可以分。

**G3｜（Q15）你急需一筆錢，歸還時間說不準，找{名字}借。她會？**

- A：先借你一部分，還款的事之後再說。
- B：先問清楚什麼時候還，再決定。

**G4｜（Q21）{名字}爸媽說要出首付，條件是買在他們家附近。她會？**

- A：沒什麼衝突就接受了。
- B：不合自己的計畫，寧願晚點買。

**G5｜（Q23）爸媽希望{名字}長期資助已經成年的弟妹。她會？**

- A：一家人就是互相托底。
- B：可以幫，但要有期限。

**G6｜（Q24）{名字}想搬去別的城市，爸媽反對。她會？**

- A：先溝通，必要時延後。
- B：聽完意見，還是自己決定。

**G7｜（Q25）你做了一件傷到別人的事，{名字}會？**

- A：先陪你、穩住你，再談怎麼負責。
- B：先直接跟你說：「這樣不對。」

**G8｜（Q26）你們幾個月沒聯絡，{名字}心裡會覺得？**

- A：沒差，見面照樣很熟。
- B：有點在意，希望有人主動一點。

**G9｜（Q28）你辦了一場超出{名字}預算的生日局，她會？**

- A：咬牙也要來。
- B：坦白說預算不夠，另外單獨幫你慶祝。

**G10｜（Q29）每天花一小時化妝打扮，{名字}覺得？**

- A：值得，好看讓我開心一整天。
- B：太久了，能簡化就簡化。

**G11｜（Q33）{名字}有一筆可以自由花的錢，她會？**

- A：先存起來。
- B：拿去旅行或做一件期待很久的事。

**G12｜（Q36）{名字}衣櫃已經很滿了，又看到超喜歡的新款。她會？**

- A：先把舊的清掉再說。
- B：預算夠就買，換風格本來就是樂趣。

## 第三關：猜標籤

抽卡規則與男生版相同：12張卡＝N張真卡＋N張反面卡＋干擾卡，隨機排列，她有幾張，閨蜜就選幾張。兩個差別：

- 第1、2對戀愛標籤預設可以進入卡池。
- 婚育標籤（第3、4對）只有在她勾選開放後，才會出現。

**題目：** 這12張裡，哪幾張是{名字}本人？選{N}張。

## 第四關：閨蜜限定，哪句最戳她？

這一關只有她開放「扎心句」後才會解鎖，是閨蜜版獨有的關卡，也是最能證明默契的一關。

**玩法：** 閨蜜看到4句扎心句：1句來自她真實標籤中最高分的那個，另外3句從其他標籤隨機抽取。閨蜜要選出哪一句最戳{名字}。

**題目：** 這4句話裡，哪一句說中{名字}、會讓她沉默三秒？

**加分題（選填）：** 用一句話吐槽{名字}，她看了會笑的那種。這句話會出現在她的結果頁。

**防護規則：**

- 吐槽欄位加上提示：「開玩笑可以，別傷到她喔。」
- 系統過濾外貌、身材、體重相關的字詞，以及診斷式用語（例如「回避型」「有病」），命中時請閨蜜改寫。
- 她可以一鍵隱藏任何一則吐槽。

## 結果頁文案

結構與男生版相同：她看到完整對照，閨蜜只看到得分。閨蜜版多了第四關結果，以及可以和男生版並排比較的「閨蜜 vs 他」畫面。

### 她看到的版本

**標題：** {閨蜜名字}眼中的你

> 她以為你是：{猜的型名} 其實你是：{真實型名} 她看懂了你的 {x}/6 面。

| 第一關猜中 | 文案 |
| --- | --- |
| 6/6 | 認證靈魂姐妹。她可能比你還懂你。 |
| 4–5/6 | 她懂你大部分的樣子，剩下的，你還藏在心裡。 |
| 2–3/6 | 她認識的是跟她在一起時的你。其他時候的你，她還沒見過。 |
| 0–1/6 | 她眼中的你和本人差很多，今晚奶茶你請，好好聊聊。 |

**三區內容：** 她看懂的你／她沒看見的你／她以為的你，規則與男生版相同。

**第四關結果：**

- 猜中：「她一眼就挑中戳你的那一句。這就是閨蜜。」
- 沒猜中：「她以為戳你的是『{她選的句子}』，其實是『{真實句子}』。」
- 附上閨蜜的吐槽（若有填寫，且未被她隱藏）。

### 閨蜜 vs 他（跨版本對照）

她同時把男生版和閨蜜版發出去，並且兩邊都有人作答後，才會解鎖這個畫面。

| 顯示項目 | 內容 |
| --- | --- |
| 誰更懂你 | 比較第一、三關的猜中數：「在懂你這件事上，{閨蜜}贏了{他}2格。」 |
| 共同看見的你 | 兩人都猜中的軸或標籤：「這一面，你藏不住。」 |
| 只有她看見的你 | 閨蜜猜中、他沒猜中：「這一面，你只給姐妹看。」 |
| 只有他看見的你 | 他猜中、閨蜜沒猜中：「這一面，你只在他面前出現。」 |
| 兩人都沒看見的你 | 兩人都漏掉的標籤：「這一面，連他們都還不知道。」 |

這個畫面只有她看得到，不會通知閨蜜或男生。分享時只能分享她勾選的格子。

### 閨蜜看到的版本

> 你看懂了{名字}的 {x}/6 面。想知道你漏掉了哪一面？去問她。

**回流：** 「換你測，看她是不是也最懂你」。
